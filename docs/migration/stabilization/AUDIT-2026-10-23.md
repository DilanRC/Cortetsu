## 3. Reglas de capa: mecanismo real

Medido en un Hyprland 0.56.2 anidado con la misma estructura (`dofile` a través de `dotfiles/current`) y una capa con
`blur` sobre un fondo de cuadros (fracción de píxeles grises):

| Paso | Resultado |
|---|---|
| Cambiar el symlink `current` sin recargar | 0,02: **no** se aplica |
| `hyprctl reload config-only` | 0,72: se aplica **a la superficie ya mapeada**, sin reiniciar Quickshell |
| Log de Hyprland | la recarga no escribe nada |
| Coincidencia de `namespace` | nombre completo: `launcher` (Fuzzel) no alcanza `cortetsu-launcher` |

Recargar Quickshell no recarga las reglas de Hyprland, y Hyprland no ofrece una lista de las reglas en vigor. Superficies
vivas: `background`, `drawers`, `dashboard`, `launcher`, `session`, `retained-surfaces` (por monitor); `area-picker` y
`border-exclusion` solo bajo demanda.

## 4. Prueba supervisada HDMI + `s2idle`

```sh
scripts/verification/hdmi-s2idle-supervised.sh preflight          # solo lectura (PASS el 2026-10-23)
scripts/verification/hdmi-s2idle-supervised.sh run --authorized   # una suspensión; escribir SUSPENDER
scripts/verification/hdmi-s2idle-supervised.sh recover            # DPMS off/on solo del HDMI
```

Lado del PC: `dpmsStatus` de Hyprland, `status/enabled/dpms` del conector DRM, captura de `HDMI-A-1` con límite de 6 s
(un congelado colgó `grim` el 2026-10-20), errores de commit en el log de Hyprland, journal del kernel y del shell,
IRQ de despertar. Lado del monitor: tres preguntas registradas. Veredictos: `OK`, `ASLEEP` (sin señal y DPMS apagado;
una tecla lo despierta), `FROZEN` (imagen fija con DPMS encendido o captura colgada), `LINK_LOST` (sin señal con DPMS
encendido). Recuperación validada en el anidado: `hl.dsp.dpms({ action = "off"|"on", monitor = ... })`; eDP-1 sigue
disponible siempre. Evidencia en `~/.local/state/cortetsu/qa/hdmi-s2idle-<fecha>/`.
